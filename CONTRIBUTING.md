# Contributing

This Topo Project welcomes external contributions. Contributions are licensed under the [Apache License 2.0](LICENSE).

## Certify the contribution origin

Before submitting a contribution, certify its origin under the [Developer Certificate of Origin (DCO) Version 1.1](https://developercertificate.org/).

Sign off every commit with your real name and email address:

```text
Signed-off-by: FIRST_NAME LAST_NAME <your@email.address>
```

To add the sign-off automatically, use the `-s` option when you commit:

```bash
git commit -s
```

Pseudonyms and anonymous contributions are not accepted.

## Submit a change

1. Fork the repository and create a branch for your change.
2. Make the smallest change that solves the problem.
3. Run the applicable tests and formatting checks.
4. Commit the change with a DCO sign-off.
5. Open a [pull request from your fork](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/creating-a-pull-request-from-a-fork).

All changes must pass code review before they can be merged into the `main` branch.
